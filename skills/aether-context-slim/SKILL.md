# Aether Context Slim (v1.0.0)

Treat long instruction files as routers, not warehouses. Always-on rules stay; task detail moves to on-demand docs/skills with a clear index. Prefer existing CAT skills via companions before creating new ones. Never drop safety, sovereignty, or HITL rules.
