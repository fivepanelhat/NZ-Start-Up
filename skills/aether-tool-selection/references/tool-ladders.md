# Reference tool ladders (load on demand)

## Skill authoring step
1. read_file (existing skill / template)
2. write_file / edit_file (local draft)
3. GitHub push_files + create_pull_request (after HITL)

## Repo investigation
1. Local bash (ls, rg, git status) if clone present
2. GitHub get_file_contents / get_repository_tree
3. browse_page only if README not in API

## Public NZ fact check (Companies Office, IRD guidance)
1. web_search with site: operators
2. browse_page on official URL
3. Never invent numbers

## Edge / node
1. Local health probes (cat-doctor patterns)
2. Explicit network only if user requested remote check
3. Refuse silent cloud phone-home
