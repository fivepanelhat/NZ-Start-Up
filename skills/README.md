# Skills (public evaluation layer)

**Coastal Alpine Tech Limited — NZ Start-Up**

This directory lists **digital employee names, roles, and autonomy ceilings** for evaluation and portfolio credibility.

## What is public

- Skill identity (name, role summary)
- HITL / autonomy ceiling
- Cultural sensitivity flags where relevant

## What is not public

Full procedures, checklists, templates, routing tables, Sprintit rubrics, report packs, and jurisdiction-depth context are **commercial-track only** (Track B under the dual licence).

| Layer | Access |
|-------|--------|
| Role cards / stubs | Public evaluation (Track A) |
| Operating procedures & templates | Written commercial agreement |
| Sprintit AI method & report packs | Sprintit / commercial delivery only |
| Pricing & cohort terms | Not published |

**Do not treat public skill files as a complete operating system.** Competitors and evaluators see posture and ceilings — not the sellable context layer.

See [docs/DUAL_LICENCE.md](../docs/DUAL_LICENCE.md) and the repository README commercial boundary section.
