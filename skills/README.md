# Skills (public evaluation layer)

Coastal Alpine Tech maintains a fleet of **93 named, versioned skills**. They are customisable for any industry under the same HITL and Te Mana Raraunga contract.

This public repository shows **one working set** — **Founder OS**:

- `formation-officer`
- `nz-company-formation` (procedure private; role card here)
- `compliance-registrar`
- `finance-clerk`
- `legal-document-assistant`
- `nz-startup-launch-sequence` (role card; full calendar private)

Other folders in this directory are **name cards** only.

## What is public

- Skill identity, HITL / autonomy ceiling, cultural-sensitivity flags
- Fleet count (93) and the customisable-for-any-industry claim

## What is not public

Full procedures, checklists, templates, Sprintit rubrics, report packs, funding scores, and prices. Those load from the private CAT Agent Harness under a written agreement (Track B / dual licence).

Do not treat public skill files as a complete operating system.

See [docs/DUAL_LICENCE.md](../docs/DUAL_LICENCE.md).

Humans still advise, decide, sign, file, send, and pay. A skill cannot raise that ceiling.
