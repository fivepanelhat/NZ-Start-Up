# Aether Skill Forge (v1.0.0)

## Four-step forge
1. Intent — job, triggers, success criteria, side-effect class, HITL level, sovereignty scope.
2. Structure — name, description, body outline, references/assets, companions.
3. Author — CAT frontmatter, progressive disclosure, anti-rationalization, verification section.
4. Gate — HITL approval, propose eval, register companions.

Never write production skill files without explicit approval on medium/high-stakes domains.
