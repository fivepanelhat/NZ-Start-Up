# NZ Incorporation + Day-0 Checklist

DRAFT — NOT FOR SUBMISSION. Founder files in their own RealMe session.

## Pre-incorporation

- [ ] Decide legal name + 2 backups (confirm availability on Companies Register)
- [ ] Confirm entity type (typically NZ limited company)
- [ ] Directors / shareholders details ready (names, addresses, DOB)
- [ ] Registered office / address for service
- [ ] Share structure decided (note future ESOP gap if desired)
- [ ] Constitution vs Companies Act default — discuss with advisor if needed
- [ ] RealMe login tested
- [ ] Payment method ready for Companies Office fee

## Incorporation day (online)

- [ ] Complete online incorporation + payment via Companies Office
- [ ] Wait for confirmation email and status = **Registered**
- [ ] Record Company Number and NZBN immediately

## Immediately after status = Registered

- [ ] Download **Certificate of Incorporation** (PDF)
- [ ] Download **Company Extract** (PDF) — keep a copy dated today
- [ ] Save both to a dedicated folder + email copies to yourself
- [ ] Record: Company Number _______________  NZBN _______________

Links: [companies-register.companiesoffice.govt.nz](https://companies-register.companiesoffice.govt.nz) → search company → Company Extract / Certificate

## Company IRD number

- [ ] Apply online for non-individual IRD number (upload Certificate of Incorporation)
- [ ] Note application reference / confirmation
- [ ] When IRD number arrives → record it: IRD _______________

A limited company needs its **own** IRD number (cannot use a personal one).

## Business bank account

- [ ] Submit application with Certificate + current Company Extract attached
- [ ] Provide director ID + proof of address for all signatories
- [ ] Record application reference / expected activation date
- [ ] Preferred bank: ___________________________

Typical activation: 3–10 business days. Prioritise banks with strong Xero feeds (BNZ / ASB / ANZ / Westpac).

## Xero (or equivalent)

- [ ] Create organisation (company name, NZ, year-end usually 31 March)
- [ ] Enter company IRD number once received
- [ ] Connect bank feed once account is active
- [ ] Customise invoice template + basic chart of accounts

## GST registration

- [ ] Decide voluntary vs compulsory (threshold $60k; voluntary often useful for claiming setup GST)
- [ ] Register via myIR once company IRD is live — choose filing frequency + accounting basis
- [ ] Update Xero with GST details
- [ ] GST / IRD number (same): _______________
